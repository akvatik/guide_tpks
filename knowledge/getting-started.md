# Помощник по ТПКС

Репозиторий `akvatik/guide_tpks` содержит материалы курса и исходный код
скилла `tpks-kozyrev`. Он помогает выбирать проект, готовить документы,
проверять согласованность и готовиться к защите с опорой на источники.
Переобучение модели и отдельный сервер не нужны.

## Начать работу

Открыть этот репозиторий в клиенте Codex, поддерживающем проектные скиллы.
Попросить: «Используй $tpks-kozyrev и предложи три темы проекта по материалам
курса». Если клиент не обнаружил скилл, явно попросить прочитать
`.agents/skills/tpks-kozyrev/SKILL.md`. В обычном чате также нужен доступ
к материалам: одна ссылка на файл скилла их не загружает.

Примеры запросов:

- «Объясни свойства требований именно по слайдам, укажи страницы».
- «Проверь этот стандарт: замечания, основания и варианты исправления».
- «Сравни две темы по объёму работ и тому, какие методы курса они позволяют показать».
- «Подготовь вопросы к защите моего плана управления конфигурацией».

## Что пока неизвестно

Тема, команда, задание и даты пользователя ещё не подтверждены. Они хранятся
в `project-profile.json` как пустые значения. После выбора темы заполнить
профиль подтверждёнными сведениями и поменять `status` на `confirmed`.
Не брать чужие сведения из `docs/project.tex` автоматически.

`docs/`, `pdf/`, прежний README и заметки про DPM унаследованы от
`kbrylkina/tpks`. Они сохранены как примеры. «Сделай на субботу» пока не
определяет задание пользователя: старый календарь принадлежит исходной команде.
Прежняя инструкция агента сохранена в `inherited/AGENTS.original.md` для справки.

## Найти подтверждение

Команды выполнять из корня репозитория. Требуется Python 3.10+; дополнительных
пакетов для поиска не нужно.

```sh
python .agents/skills/tpks-kozyrev/scripts/course.py search "базовая версия" --kind slides
python .agents/skills/tpks-kozyrev/scripts/course.py show materials/kozyrev_slides/Vse_kozyrev.pdf.txt --page 22
python .agents/skills/tpks-kozyrev/scripts/course.py check
```

Поиск буквальный, без русской морфологии: при необходимости искать корень
слова или использовать `--regex`. Все слова запроса должны находиться на
одной странице PDF или в окне 30 строк. Отсутствие совпадения не доказывает
отсутствие правила. Схемы нужно смотреть в оригинальном PDF.

Каталог `sources.json` содержит происхождение, пути, SHA-256 и доступность
текста. Для текстовых файлов хеш и размер нормализованы к UTF-8/LF, поэтому
перенос репозитория между Windows и Linux не делает каталог устаревшим.
После добавления или изменения материалов выполнить:

```sh
python .agents/skills/tpks-kozyrev/scripts/course.py catalog
python .agents/skills/tpks-kozyrev/scripts/course.py check
python -m unittest discover -s tests -v
```

Оригиналы не исправлять ради совпадения с пересказом. Новые замечания
преподавателя сохранять в `feedback.md` вместе с датой, документом и контекстом.
Правила с проверенными основаниями добавлять в `rules.json`, сохраняя
различие между текстом источника, интерпретацией и студенческим отзывом.
Хеш источника в каждом основании менять только после повторной проверки
правила. Перестроение каталога не подтверждает старые правила автоматически.

## Пределы первой версии

- Существующие материалы инвентаризированы, но не каждый тезис заново проверен.
- Проверенное ядро `rules.json` намеренно небольшое. Схемы PDF 18 и 73
  визуально проверены при подготовке; остальная разметка не означает сплошной проверки рисунков.
- Стандарты, на которые ссылаются заметки, не вложены в этот репозиторий.
- Автоматические проверки находят устаревший каталог и неправильные адреса
  доказательств; качество содержания оценивается отдельно.
- Это проектный скилл, а не установленный личный скилл во всех чатах аккаунта.
